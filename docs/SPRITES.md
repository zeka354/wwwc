# Как рисовать спрайты для игры

Чтобы анимации стыковались без скачков в размере и качестве, все листы делаются по одному стандарту.

## Стандарт

| Параметр | Значение |
|---|---|
| Эталон | `reference_eiris.png`: прикладывать к каждой генерации |
| Кадр | 256 × 256 px, все кадры одинаковые, в один ряд (или сетка без промежутков) |
| Рост | 180 px от подошвы до кончиков рогов в обычной стойке |
| Земля | ноги на одной линии: 20 px от нижнего края кадра |
| Центр | тело по центру кадра, не уезжает влево-вправо (кроме шага/выпада) |
| Вид | сбоку, смотрит вправо, тот же угол, что у эталона |
| Фон | сплошной ярко-зелёный `#00FF00`, без теней, свечения, виньетки, градиента |
| На листе | только кадры: без подписей, номеров, рамок, панелей |
| Эффекты | дуги, круги, искры отдельным листом на том же фоне и в тех же кадрах |

Шаблон с разметкой: `sprite_template.png` (8 кадров 256 × 256, линия земли, линия роста, центр).

## Порядок

1. Стойка (idle), 8 кадров. От неё зависят все остальные.
2. Ходьба, 8 кадров. Первый кадр должен совпадать со стойкой.
3. Бег 8, урон 4, смерть 8.
4. Остальное: прыжок, атаки, магия, AFK можно перерисовать по этому же стандарту позже.

## Пример запроса для генератора

> Pixel art sprite sheet, 8 frames in one row, each frame 256x256, character from the reference image, exactly the same design, proportions and colors, side view facing right, character height 180 px from feet to horn tips, feet on the same baseline 20 px above the bottom of each frame, centered, idle breathing animation, flat solid #00FF00 background, no shadows, no glow, no text, no numbers, no borders.
