# Багровая Жрица

2D-экшен-платформер в браузере (HTML5 Canvas, без движков и библиотек). Жрица идёт по стене готического замка, бьёт теней посохом, колдует круг крови и в конце сражается со своей Тенью.

## Как запустить

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом нельзя: браузер не даст загрузить картинки с `file://`. Нужен любой локальный сервер.

## Управление

| ПК | Телефон | Действие |
|---|---|---|
| A / D, ← / → | ◀ ▶ | идти; удерживай — переход в бег |
| Shift | — | сразу бег |
| Пробел / W / ↑ | ▲ | прыжок; в воздухе — второй прыжок с переворотом |
| J / Z | ⚔ | удар; жми ещё — серия из трёх ударов, третий сильнее |
| K / X | ✦ | священный ритуал: столбы света вокруг, 40 маны, не прерывается уроном |
| L / C | ⟲ | кувырок, во время него удары проходят мимо |
| S / ↓ | — | присесть; S + Пробел — спрыгнуть с платформы |
| P / Esc | ❚❚ | пауза |

Если 30 секунд ничего не нажимать, Эйрис начинает AFK-анимацию: оглядывается, зевает, творит печать (в это время быстрее копится мана).

## Структура

- `game/index.html` — вся игра: код, интерфейс, синтезированный звук.
- `game/assets/` — готовые полосы кадров (`walk`, `run`, `jump`, `attack`, `cast`, `idle`, `crouch`, `shadow_*`), портрет и фоны. Кадр 288×176, точка ног (144, 170), персонаж смотрит вправо. Параметры в `anims.json`.
- `source/` — исходные спрайт-листы и арты.
- `tools/smoke_test.js` — автотест в браузере: `node tools/smoke_test.js` (нужен `npm i -D playwright`).
- `docs/SPRITES.md` — как просить новые спрайты у ChatGPT.
- `CLAUDE.md` — контекст проекта для Claude Code.
- `tools/build.py` — нарезает кадры из `source/`: убирает тёмный фон, делит лист на кадры, выравнивает по ногам и центру тела, приводит к одному росту (128 px), красит копию жрицы в тень-врага.

Пересобрать ассеты:

```bash
pip install pillow numpy scipy
python3 tools/build.py          # PREVIEW_DIR=/путь — сохранить превью
```

## Откуда какие кадры

| Анимация в игре | Лист | Кадры |
|---|---|---|
| `walk` (15) | `walk_run_extra.png`, 1-й ряд | все |
| `run` (22) | `walk_run_extra.png`, 2-й ряд | все |
| `idle2` (4) | `v3_afk_yawn.png` | спокойные кадры 1, 4, 5, 8 |
| `combo12` (12) | `v2_combo12.png` | серия: 2–4, 5–7, 8–12 |
| `ritual` (12) | `v2_ritual12.png` | все |
| `jump2` (12) | `v2_jump.png` | все |
| `roll` (14) | `v2_roll.png` | 3–13 кувырок, 5–8 переворот во втором прыжке |
| `afk2` (16) | `v3_afk_yawn.png` + `v3_afk_magic.png` | все; после 30 с без управления, любая кнопка прерывает |
| `squat` (10) | `v2_crouch.png` | присед, жёсткое приземление, урон, падение |
| `shadow_walk`, `shadow_combo` | те же, перекрашенные | враги и босс |

Листы со светлым фоном (`guide_*.png`, `character_sheet.png`) пока не нарезаны: фон по цвету почти совпадает с одеждой, их проще перерисовать на тёмном или прозрачном фоне. Оттуда можно взять смерть, воскрешение, 8 направлений и эмоции.
