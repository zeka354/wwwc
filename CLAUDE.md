# Багровая Жрица — контекст для Claude Code

Браузерный 2D-экшен-платформер про Эйрис, жрицу алой печати. Автор присылает спрайт-листы (генерирует их в ChatGPT), Claude нарезает кадры скриптом и встраивает в игру.

## Общение

- Автор пишет по-русски, неформально («бро»). Отвечай по-русски, просто и коротко, без жаргона.
- Автор играет в основном с телефона (Android, горизонтально). Любое изменение проверяй и в мобильной раскладке.
- Новые картинки от автора кладутся в `source/` с понятным именем (`v4_walk.png` и т. п.), затем нарезаются через `tools/build.py`.

## Структура

```
game/index.html      вся игра: HTML + CSS + JS в одном файле, без библиотек и сборки
game/assets/         готовые полосы кадров (PNG, кадр 288×176) + фоны + портрет; генерируются скриптом
source/              исходные листы и арты от автора, не редактировать
tools/build.py       нарезка всех анимаций из source/ в game/assets/
tools/lib.py         функции нарезки: маска фона, деление на кадры, выравнивание
tools/smoke_test.js  автотест в headless Chromium
docs/SPRITES.md      как автору просить спрайты у ChatGPT (шаблон запроса)
docs/reference_eiris.png, docs/layout_example.png   эталон персонажа и пример формата листа
```

## Команды

```bash
# запустить игру (с file:// картинки не загрузятся)
cd game && python3 -m http.server 8000      # http://localhost:8000

# пересобрать ассеты из source/
pip install -r tools/requirements.txt
python3 tools/build.py
PREVIEW_DIR=/tmp/prev python3 tools/build.py   # плюс превью-листы prev_<анимация>.png

# автотест: серия ударов, ритуал, кувырок, двойной прыжок, AFK; падает на любой JS-ошибке
npm i -D playwright && npx playwright install chromium   # один раз
node tools/smoke_test.js
```

После каждого изменения игры запускай `node tools/smoke_test.js`. Для визуальной проверки делай скриншот через Playwright, в том числе с эмуляцией телефона (`devices['Pixel 7 landscape']`).

## Формат кадров

- Все полосы: кадры 288×176 в один ряд, точка ног (144, 170), персонаж смотрит вправо (влево отражается в коде).
- Рост персонажа в стойке: 128 px (`TARGET` в `build.py`). Каждую анимацию масштабируй к этому росту.
- В конце `build.py` все полосы подгоняются по цвету под `idle2` (гистограммы). Новую анимацию персонажа добавляй в этот список.
- Враги «тени»: те же кадры, перекрашенные функцией `shade()` (`shadow_walk`, `shadow_combo`).

## Как нарезать новый лист

Лучший формат от автора: сетка 4×2, 8 крупных кадров, тёмный однотонный фон, без подписей (как `source/v3_afk_*.png`). Для такого листа:

```python
fr = grid_frames('source/v4_walk.png', baselines=[y_ног_ряд1, y_ног_ряд2])   # y ног в пикселях листа
cells = place_grid(fr, TARGET / body_metrics(fr[0]['m'])['h'])
save('walk3', cells, fps, loop)
```

`y_ног` смотри по `body_metrics(...)['bot']` для каждой ячейки (пример есть в истории: ряды с одинаковой линией земли). Для листов другого вида есть `blobs_rows` (кадры отдельно на ровном фоне), `panels` (сетка карточек с подписями), `auto_cuts` + `extract` (кадры в ряд). Маска фона: `mask_of(a, 55)`; `soft_rgba` даёт мягкую прозрачность красному свечению эффектов.

Потом в `game/index.html`: добавь имя и число кадров в `ANIM`, используй в `playerFrame()` и, если нужно, в логике `updatePlayer()`.

## Устройство игры (`game/index.html`)

- Логическое разрешение: высота 540, ширина `W` от 960 до 1280 (подстраивается под экран телефона), см. `resize()`.
- Константы: `GROUND` (уровень пола), `LEVEL_W`, `LEFT` (ворота на старте), `ARENA_X` (арена босса).
- `ANIM`: имена полос и число кадров; загружаются из `assets/<имя>.png`.
- `COMBO`: три удара серии `[первый кадр, последний, кадр попадания, fps, урон, дальность, отброс]`.
- `AFK_DUR`: длительность каждого кадра AFK. AFK включается после 30 с без ввода, любая кнопка (`poke`) прерывает.
- Игрок: `updatePlayer()` — конечный автомат состояний `idle / walk / run / air / land / attack / cast / roll / crouch / standup / hurt / afk / dead`; `playerFrame()` выбирает кадр под состояние.
- Враги: `spawn(type)`, типы `shadow`, `wisp` (огонёк, рисуется в коде), `boss`; атаки в `enemyAttack()`.
- Уровень: `PLATFORMS` (односторонние платформы), `WAVES` (волны врагов по координате X игрока), фонари, фон из `bg_castle.jpg` с параллаксом, арки рисуются в `buildLayers()`.
- Звук синтезируется в коде (`Snd`), файлов нет.
- Управление: клавиатура (`KEYMAP`) и сенсорные кнопки `#touch` (◀ ▶ ⚔ ▲ ✦ ⟲).

## Что дальше (план с автором)

1. Новые ходьба и бег в формате 4×2 (уберут скачок стойка → шаг).
2. Получение урона (4–8 кадров) и смерть (8 кадров), сейчас подменены кадрами приседа.
3. Свои враги вместо перекрашенной Эйрис.
4. Локации: автор пришлёт фоны слоями, тайлы, предметы; под каждую локацию свой уровень (собор, подземелье, кладбище…). Тогда уровень лучше вынести из констант в данные (массив уровней).
